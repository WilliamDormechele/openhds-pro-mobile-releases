# OpenHDS Pro 2.0.117

## Fixed

- Region search now works immediately when Household fieldwork opens.
- Fieldworkers no longer need to tap the Region button before searching by Region name or ID.
- District, Village and Sub-village searches continue to switch to the correct hierarchy level after selection.

Install this APK over the existing OpenHDS Pro app. Do not uninstall the app, because uninstalling removes locally stored application data.
