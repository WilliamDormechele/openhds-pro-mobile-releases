# OpenHDS Pro 2.0.116

- Dashboard totals and drill-downs use the same stored ODK records.
- Weekly household visits are counted by unique Visit Registration and calendar day; today is highlighted in amber.
- Missed Vaccination is counted for each resident under-five member in a visited household.
- PG/NB follow-up compares the latest Pregnancy Observation with the latest Pregnancy Outcome in visited households.
- Duplicate records remain included in operational totals and are reported separately by data quality.
- Finishing a household visit returns to the same compound for remaining households.
- Member search covers the complete joined surveillance population and displays Resident, DTH and OMG status.
