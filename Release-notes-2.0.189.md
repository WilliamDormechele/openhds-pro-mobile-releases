# OpenHDS Pro 2.0.189

- Hardened household-scoped fieldwork and compound navigation.
- Compound level now shows destination households only; household members open only after a household is selected.
- Restricted Finish Visit to an active selected-household visit.
- Hardened internal migration and destination-only membership assignment.
- Added governed Membership required handling for unresolved current residents.
- Removed historical/origin households from destination household selection and counts.
- Corrected household-head eligibility using canonical DOB and supported HDSS date formats.
- HH now identifies only the current head of the selected household; former household-head status does not carry across migration.
- Hardened ODK companion launching and resolved location, migration and completed-visit return crashes.
- Preserves existing field data during an in-place upgrade.
