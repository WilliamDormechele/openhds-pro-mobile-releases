# OpenHDS Pro 2.0.113

## Fixed

- OpenHDS verifies that a saved ODK draft still exists before attempting to reopen it.
- A removed or unavailable draft no longer opens ODK's "Form can't be used / Bad URI" screen.
- The recovery message identifies the affected form, confirms that no completed record was removed, and links back to the household so the required form can be restarted safely.

## Safe update

Install this APK over the existing OpenHDS Pro installation. Do not uninstall the current app, because uninstalling can remove locally stored fieldwork.
